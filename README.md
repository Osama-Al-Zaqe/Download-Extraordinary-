# MediaFlow — تطبيق متكامل لتنزيل وإدارة الوسائط

**MediaFlow** هو تطبيق احترافي متكامل لتنزيل مقاطع الفيديو، والصوتيات عالية الجودة، والصور المصغرة، والترجمات، والأوصاف والمعلومات الوصفية، والبحث المباشر في YouTube وتنزيل النتائج جماعياً، وإدارة القنوات وقوائم التشغيل، وتنظيم كافة الملفات تلقائياً، مع دعم كامل للاستكمال التلقائي عند انقطاع الإنترنت.

---

## 🌟 أبرز مميزات التطبيق

1. **واجهة مستخدم عصرية واحترافية (Glassmorphic Dashboard):**
   * تصميم حديث يعتمد على أحدث معايير HTML5 وCSS3 مع تأثيرات زجاجية خفيفة.
   * دعم أصيل وكامل للغة العربية واتجاه النص من اليمين إلى اليسار (RTL) مع إمكانية التبديل إلى الإنجليزية (LTR) بضغطة زر.
   * وضعان بصريان: **الوضع الداكن (Dark Mode)** و**الوضع الفاتح (Light Mode)**.
   * أشرطة تقدم لحظية، مؤشرات سرعة دقيقة، وحساب الوقت المتبقي (ETA).

2. **تحليل وتنزيل الوسائط من الروابط:**
   * دعم منصات الوسائط العالمية: YouTube، Facebook، TikTok، Instagram، Twitter/X، وغيرها عبر محرك `yt-dlp`.
   * استخراج تفاصيل المحتوى: العنوان، القناة، المدة، المشاهدات، الصورة المصغرة، والوصف.
   * إمكانية الاختيار بين: فيديو وصوت (بجودات متعددة تصل إلى 4K)، أو صوت فقط (MP3, M4A, FLAC, OPUS).
   * تنزيل الصور المصغرة والترجمات وحفظ الأوصاف والبيانات الوصفية في ملفات منفصلة (`.txt` و`.json`).

3. **صفحة بحث مستقلة في YouTube:**
   * إمكانية البحث المباشر بكتابة عبارة مثل: `سورة مريم`.
   * عرض النتائج الحقيقية ببطاقات تفاعلية تشمل الصورة المصغرة، العنوان، اسم القناة، والمدة.
   * تحديد فيديو فردي، أو تحديد عناصر متعددة، أو تحديد جميع النتائج بضغطة واحدة.
   * تنزيل جماعي منظم داخل مجلد مخصص لكل عبارة بحث:
     `MediaFlow Downloads/YouTube/Searches/عبارة البحث/`
   * تسمية الملفات بصيغة معيارية آمنة: `اسم الفيديو (اسم القناة).ext`.

4. **تنزيل القنوات وقوائم التشغيل (Playlists & Channels):**
   * جلب عناصر القائمة بسرعة وأمان مع عرض إجمالي عدد العناصر والمدة التراكمية.
   * إمكانية اختيار عناصر محددة أو تنزيل القائمة كاملة مع الحفاظ على ترقيم وترتيب العناصر (`01 - Title.mp4`).
   * تنظيم المجلدات وفق التسلسل المعياري:
     `MediaFlow Downloads/YouTube/اسم القناة/اسم قائمة التشغيل/`
     أما المقاطع المنفردة للقناة فتنظم داخل مجلد القناة مباشرة دون تكرار مجلدات موجودة.

5. **نظام الاستكمال التلقائي الذكي عند انقطاع الإنترنت (Smart Resume Engine):**
   * اكتشاف انقطاع الشبكة فور حدوثه وإيقاف المحاولات مؤقتاً لتجنب إهدار موارد النظام.
   * الحفاظ التام على الملفات الجزئية (`.part` و`.ytdl`) دون تلف أو دمج غير متوافق.
   * حفظ حالة كل مهمة محلياً في قاعدة بيانات SQLite.
   * مراقبة خفيفة ومستمرة لعودة الاتصال، تليها محاولة الاستكمال باستخدام تأخير تصاعدي (Exponential Backoff).
   * استعادة المهام غير المكتملة تلقائياً عند إعادة تشغيل التطبيق.
   * حالات دقيقة لكل مهمة: `قيد الانتظار`، `جارٍ التنزيل`، `متوقف بسبب الشبكة`، `جارٍ الاستكمال`، `جارٍ المعالجة والدمج`، `مكتمل`، و`فشل`.

6. **طابور تنزيلات متقدم وإدارة الأداء:**
   * تحديد سقف التنزيلات المتزامنة (1 - 10 مهام معاً) لمنع استهلاك النطاق الترددي وموارد المعالج.
   * أزرار تحكم كاملة: إيقاف مؤقت، استئناف، إعادة محاولة، إلغاء، وإيقاف/استئناف الكل.
   * تشغيل في خيوط خلفية مستقلة (Worker Threads) لضمان بقاء الواجهة سريعة الاستجابة ولا تتجمد مطلقاً.

7. **مكتبة وسائط داخلية (Media Library):**
   * فهرسة الملفات المكتملة تلقائياً مع خيارات الفرز حسب الحجم والتاريخ والاسم.
   * تصنيف الوسائط: فيديوهات، صوتيات، صور مصغرة.
   * فتح الملفات مباشرة بالمشغل الافتراضي للنظام، أو فتح المجلد الحاوي داخل File Explorer.
   * إمكانية إعادة التسمية وحذف الملفات بأمان.

8. **صفحة إعدادات شاملة وأمان عالي:**
   * تخصيص مجلد التنزيل وسياسة التعامل مع الملفات المكررة (تخطي الملف، استبداله، أو حفظ نسخة جديدة برقم إضافي).
   * إعدادات الجودة والصيغ الافتراضية، وخيارات الترجمة وحفظ الأوصاف.
   * فحص جاهزية أدوات FFmpeg ومحرك yt-dlp ومساحة القرص المتوفرة.
   * تصدير واستيراد الإعدادات بصيغة JSON.
   * حماية النظام من حقن الأوامر أو الوصول غير المصرح به للمسارات عبر تنظيف صارم للمدخلات والمسارات.

## 🚀 متطلبات التثبيت والتشغيل

### المتطلبات الأساسية
* نظام التشغيل: Windows 10 أو 11 (أو Linux / macOS).
* مفسر Python الإصدار 3.10 أو أحدث.

### خطوات التثبيت

1. افتح موجه الأوامر (PowerShell أو CMD) في مجلد المشروع:
   ```powershell
   cd c:\Users\OSAMA\Desktop\MediaFlow
   ```

2. قم بتثبيت الحزم المطلوبة:
   ```powershell
   py -m pip install -r requirements.txt
   ```

### تشغيل التطبيق

* **عبر المشغل السريع في Windows:**
  انقر نقراً مزدوجاً على الملف:
  ```text
  run.bat
  ```

* **أو عبر سطر الأوامر:**
  ```powershell
  py main.py
  ```

* **خيارات التشغيل الإضافية:**
  * الفتح المباشر في متصفح النظام الافتراضي:
    ```powershell
    py main.py --browser
    ```
  * التشغيل كخادم خلفي فقط (Headless Mode):
    ```powershell
    py main.py --headless
    ```
  * تحديد منفذ مخصص (Port):
    ```powershell
    py main.py --port 8080
    ```

## 🔒 الأمان والمحددات التقنية الحقيقية

1. **الروابط الخاصة والمحمية:** يتعامل التطبيق مع الروابط الخاصة أو المحذوفة بعرض رسائل تنبيه واضحة بدلاً من إظهار أخطاء برمجية غامضة.
2. **أنظمة DRM والقيود القانونية:** لا يتجاوز التطبيق أنظمة التشفير الرقمي (DRM) أو ضوابط الوصول الخاصة بالمنصات.
3. **أمان المسارات والمدخلات:** يتم تنظيف كافة الروابط وأسماء الملفات والمسارات، وحجب أي محاولة لتنفيذ أوامر صدفية أو تراجع في المجلدات (`Path Traversal`).
4. **الخصوصية:** جميع بيانات المهام وسجل التنزيلات تخزن محلياً فقط على جهاز المستخدم (`SQLite`) دون إرسال أي بيانات أو سجلات لجهات خارجية.
